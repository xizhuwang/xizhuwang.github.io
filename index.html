GRADUATE RESEARCH

Adaptive Mixed-Precision Architecture for Multi-User Large Language Model Inference on HBM-Based Processing-in-Memory

My thesis studies how concurrent LLM requests can share HBM-PIM resources while balancing latency, memory capacity and inference quality. The architecture coordinates CPU-side control, scheduling, the SoC bus, HBM controller, memory banks and PIM compute units.
